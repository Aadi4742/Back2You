The Story Behind Back2You

Built by Students, for Students

Every semester, hundreds of calculators, water bottles, keys, and laptops get left behind in lecture halls, libraries, and labs. We wanted to build something faster and cleaner than scrolling through unorganized WhatsApp groups or waiting on paper logbooks at the main desk.

How It Started

The Problem We Kept Running Into

Last semester, Aditya left his scientific calculator on a desk in Lecture Hall B right after a midterm. Tracking it down took three days: asking in multiple class chats, checking with the library desk, and eventually finding out it had been handed to campus security with no note attached.

Sameer and Aditya decided to build Back2You as a weekend project that grew into a full platform. We wrote the backend in clean C++ with SQLite so it runs fast on almost any server without needing heavy frameworks. We added an automated text matching helper to spot similarities between lost reports and found items, plus a verification step so anyone claiming an item has to describe it accurately first.

Practical Design Choices

What We Kept in Mind

A few straightforward priorities we followed while building the project.

Verify Before Handover

Anyone claiming an item has to submit identifying details (like engravings, lock screens, or unique marks) before the finder confirms the handoff.

Fast and Lightweight

Using C++17 and vanilla HTML/CSS means there are no massive JavaScript bundles or runtimes required to load the site.

Direct Campus Locations

Found items link directly to real drop-off points like the Library circulation desk, central security office, or student union info point.
